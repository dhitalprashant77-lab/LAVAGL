👋 Welcome to LAVAGL!
LAVAGL is all about making the fastest graphics (Vulkan) as easy as possible. We want to make coding 3D graphics feel like "Sanity," not a headache.

🛠 How to Help
You don't need to be a C++ master to help. Here is how you can join the team:

Fork the Repo: Click the "Fork" button at the top of the page. This gives you your own copy of the code to play with.

Pick a Task: Look at the "Current Missions" below.

Make a Change: Write your code or fix a typo.

Pull Request: Send your changes back to us! Make sure to describe exactly what you changed so we can check it.

🎯 Current Missions
Simple Math: We need helper functions for 3D math (moving objects up, down, left, right).

Color Presets: Create a list of "Lava Colors" (Burning Orange, Deep Red, Obsidian Black) that users can call by name.

Bug Hunting: If the window doesn't open on your computer, tell us your GPU model in the Issues tab!

🚦 Rules
Keep it Simple: If a 14-year-old can't understand the function name, we should rename it.

Be Nice: We are all here to learn and build something cool.
